Detailed Description

Classe de associação que vincula um Projeto a um Colaborador (Pessoa).

Atua como uma entidade associativa no modelo orientado a objetos, representando a alocação de um usuário na equipe de um empreendimento. É a estrutura fundamental para a governança e o controle de acesso do sistema, determinando quais membros possuem permissão para visualizar e interagir com cada projeto.
