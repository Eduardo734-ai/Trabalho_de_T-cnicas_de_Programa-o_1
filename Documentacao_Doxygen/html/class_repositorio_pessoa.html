Detailed Description

Classe responsável pela persistência das instâncias de Pessoa no banco de dados.

  • Atua como a camada de acesso a dados (Data Access Object - DAO) para a entidade Pessoa. Encapsula os comandos SQL necessários para realizar as operações de CRUD (Criar, Ler, Atualizar, Deletar) dos usuários do sistema no SQLite, isolando a lógica de banco de dados da camada de Serviço.
