Detailed Description

Estrutura de armazenamento em memória para os vínculos de backlog de projeto.

  • Implementa um contêiner responsável por persistir temporariamente as relações que alocam histórias de usuário ao escopo global de um projeto. Esta estrutura atua como o repositório base para a camada de Serviço gerenciar os requisitos antes que eles sejam movidos para iterações específicas (sprints).
