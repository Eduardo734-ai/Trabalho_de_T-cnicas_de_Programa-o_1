Detailed Description

Determina o nível de urgência ou importância de execução de uma tarefa no escopo do projeto.

Armazena e valida o grau de relevância associado a uma história de usuário. Para garantir a correta ordenação e priorização do trabalho no modelo Scrum, os valores permitidos são estritamente limitados a "ALTA", "MEDIA" ou "BAIXA".
