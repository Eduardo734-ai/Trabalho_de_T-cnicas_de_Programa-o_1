Detailed Description

Estrutura de armazenamento em memória para os requisitos funcionais (Histórias de Usuário).

  • Implementa um contêiner responsável por gerenciar a persistência temporária das histórias de usuário na camada de Serviço. Atua como um cache ou banco de dados local, permitindo operações rápidas de inserção, busca e deleção para facilitar a validação de regras de negócio (como o cálculo de capacidade) antes da consolidação no banco de dados real.
