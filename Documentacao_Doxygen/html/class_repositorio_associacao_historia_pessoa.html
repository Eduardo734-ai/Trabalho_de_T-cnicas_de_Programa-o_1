Detailed Description

Classe responsável pela persistência do vínculo entre História de Usuário e Pessoa no banco de dados.

  • Atua como a camada de acesso a dados (DAO) para a entidade associativa. Na estrutura do banco relacional (SQLite), gerencia a tabela de junção que mapeia qual colaborador (Pessoa) é responsável por desenvolver qual requisito (História). Isola os comandos SQL de inserção, deleção e busca dessa relação.
