Detailed Description

Contrato de delegação de lógica de negócio para a gestão de usuários (Pessoas).

  • Declara a interface abstrata responsável por definir as operações de ciclo de vida (criação, leitura, atualização e exclusão) das identidades do sistema. Esta interface garante que a camada de Apresentação possa gerenciar os usuários, suas credenciais de acesso e seus papéis (níveis de permissão) sem conhecer os detalhes da implementação do banco de dados.
