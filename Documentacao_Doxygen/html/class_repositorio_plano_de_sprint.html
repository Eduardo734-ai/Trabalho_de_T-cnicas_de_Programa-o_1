Detailed Description

Classe responsável pela persistência dos Planos de Sprint no banco de dados.

  • Atua como a camada de acesso a dados (Data Access Object - DAO) para a entidade PlanoDeSprint. Isola os comandos SQL e a comunicação direta com o SQLite do resto do sistema, encapsulando as operações de CRUD (Criar, Ler, Atualizar, Deletar) referentes aos ciclos de execução (sprints) do projeto.
