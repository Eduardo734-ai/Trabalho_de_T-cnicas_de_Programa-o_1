Detailed Description

Classe de associação que vincula um Plano de Sprint a um Projeto.

Atua como uma entidade associativa no modelo orientado a objetos, estabelecendo a relação hierárquica de contenção onde um macroescopo (Projeto) possui múltiplos ciclos de execução (Sprints). É fundamental para garantir a integridade estrutural e a organização cronológica do sistema.
