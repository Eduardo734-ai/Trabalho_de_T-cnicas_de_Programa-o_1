Detailed Description

Estrutura temporal que define um ciclo de execução dentro do projeto.

Centraliza os dados de planejamento de uma iteração de trabalho (sprint), estabelecendo a sua identificação, período de vigência e o limite de esforço (capacidade) que a equipe pode absorver durante a sua execução no fluxo Scrum.
