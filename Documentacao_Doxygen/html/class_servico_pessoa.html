Detailed Description

Implementação concreta do serviço de gestão de identidades (Pessoas).

  • Esta classe materializa o contrato definido em IServicoPessoa. É responsável por orquestrar as operações de ciclo de vida dos usuários, conectando as regras de negócio à camada de persistência definitiva (banco de dados SQLite) por meio da instância de RepositorioPessoa.
