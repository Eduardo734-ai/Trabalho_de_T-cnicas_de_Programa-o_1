Detailed Description

Classe de associação que vincula uma História de Usuário a um Projeto.

Atua como uma entidade associativa no modelo orientado a objetos, representando o pertencimento de um requisito funcional ao escopo global de um projeto (Product Backlog). É a estrutura base que garante que todas as tarefas, mesmo as não alocadas em sprints, permaneçam rastreáveis dentro do seu respectivo macroescopo.
