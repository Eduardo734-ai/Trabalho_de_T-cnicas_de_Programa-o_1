Detailed Description

Classe responsável pela persistência do vínculo entre História de Usuário e Plano de Sprint no banco de dados.

  • Atua como a camada de acesso a dados (DAO) para a entidade associativa. Na estrutura do banco relacional (SQLite), gerencia a tabela de junção que mapeia a alocação de um requisito funcional (História) dentro de uma iteração específica (Plano). Isola os comandos SQL responsáveis por formar o Sprint Backlog no banco.
