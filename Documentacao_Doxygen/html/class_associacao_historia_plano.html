Detailed Description

Classe de associação que vincula uma História de Usuário a um Plano de Sprint.

Atua como uma entidade associativa no modelo orientado a objetos, representando a alocação de um requisito em um ciclo de execução específico. É essencial para gerenciar o escopo de uma iteração (sprint backlog) e permitir o cálculo da capacidade de esforço exigida pelas regras de negócio.
