Detailed Description

Classe responsável pela persistência das Histórias de Usuário no banco de dados.

  • Atua como a camada de acesso a dados (Data Access Object - DAO) para a entidade HistoriaUsuario. Isola os comandos SQL e a comunicação direta com o SQLite do resto do sistema, permitindo que a camada de Serviço apenas chame métodos de alto nível para operações de CRUD (Criar, Ler, Atualizar, Deletar) sem conhecer a tecnologia de persistência subjacente.
