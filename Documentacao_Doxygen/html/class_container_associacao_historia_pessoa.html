Detailed Description

Estrutura de armazenamento em memória para os vínculos de responsabilidade.

  • Implementa um contêiner (coleção de dados) responsável por persistir temporariamente as relações de atribuição entre as histórias de usuário e os colaboradores (Pessoas). Atua como o repositório de dados local da camada de Serviço para consultas e validações rápidas de dependência antes da persistência definitiva no banco de dados.
