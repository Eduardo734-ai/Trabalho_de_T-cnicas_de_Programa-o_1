Detailed Description

Estrutura de armazenamento em memória para os vínculos de equipe e governança de projetos.

  • Implementa um contêiner responsável por persistir temporariamente as relações de alocação entre os colaboradores (Pessoas) e os macroescopos (Projetos). Esta estrutura é essencial para a camada de Serviço validar o controle de acesso, determinando quais usuários têm permissão para atuar e visualizar quais empreendimentos antes de consultar ou atualizar o banco de dados definitivo.
