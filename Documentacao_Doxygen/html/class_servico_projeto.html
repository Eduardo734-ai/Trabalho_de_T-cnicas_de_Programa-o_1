Detailed Description

Implementação concreta do serviço de gestão e governança de Projetos.

  • Esta classe materializa o contrato definido em IServicoProjeto e atua como a orquestradora principal da camada de Serviço. É responsável por integrar múltiplos repositórios do SQLite para persistir a hierarquia do sistema (Projetos, Sprints e Backlog) e gerenciar o controle de acesso das equipes (Pessoas). Utiliza contêineres em memória para otimização do acesso a dados locais durante o processamento das regras de negócio.
