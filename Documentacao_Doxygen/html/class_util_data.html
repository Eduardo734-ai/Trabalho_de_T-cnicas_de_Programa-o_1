Detailed Description

Classe utilitária para manipulação e cálculo de intervalos temporais.

  • Implementa um conjunto de métodos estáticos responsáveis por realizar operações matemáticas sobre objetos da classe de domínio Data. Como é uma classe utilitária (stateless), não necessita ser instanciada para que suas funções sejam utilizadas pelas camadas de Serviço ou Apresentação.
