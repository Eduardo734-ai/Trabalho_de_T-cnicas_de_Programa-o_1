Detailed Description

Estrutura de armazenamento em memória para os macroescopos do sistema (Projetos).

  • Implementa um contêiner responsável por gerenciar a persistência temporária dos projetos de desenvolvimento na camada de Serviço. Atua como um repositório local que facilita operações rápidas de consulta e validação estrutural (como checagem de duplicidade de códigos) antes da consolidação definitiva no banco de dados real.
