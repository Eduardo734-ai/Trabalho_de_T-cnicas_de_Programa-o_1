Detailed Description

Implementação concreta do serviço de gestão de Planos de Sprint.

  • Esta classe materializa o contrato definido em IServicoPlanoDeSprint. É responsável por orquestrar a persistência dos ciclos de execução no banco de dados SQLite e gerenciar a alocação de tarefas (Histórias de Usuário) dentro dessas iterações. Utiliza contêineres em memória para otimizar operações locais antes de consolidar as associações físicas.
