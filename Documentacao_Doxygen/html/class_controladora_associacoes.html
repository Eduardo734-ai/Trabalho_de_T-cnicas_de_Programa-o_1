Detailed Description

Classe controladora responsável pela interface de usuário na camada de Apresentação para operações de associação.

Esta classe gerencia a navegação de menus e a captura de dados via terminal para estabelecer, remover ou listar os vínculos complexos e cardinalidades entre as entidades centrais do sistema (Pessoas, Projetos, Planos de Sprint e Histórias de Usuário). Ela valida os formatos iniciais e coordena as chamadas correspondentes na camada de Serviço para manter a integridade das regras do framework Scrum.
