Detailed Description

Contrato de delegação de lógica de negócio para a gestão de Planos de Sprint.

  • Declara a interface abstrata responsável por definir as operações de ciclo de vida (criação, leitura, atualização e exclusão) das iterações de trabalho do projeto. Esta interface garante o isolamento arquitetural, assegurando que a camada de Apresentação possa manipular os ciclos de execução sem se acoplar aos detalhes de armazenamento no banco de dados.
