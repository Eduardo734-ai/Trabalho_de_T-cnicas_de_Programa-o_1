Detailed Description

Classe de domínio que representa um conjunto de sinais, regras ou símbolos utilizados para representar informações.

Esta classe é responsável por armazenar e validar o formato de um código no sistema. De acordo com as regras de negócio, um código válido deve possuir exatamente 5 caracteres, sendo os dois primeiros letras maiúsculas (A-Z) e os três últimos dígitos (0-9).
