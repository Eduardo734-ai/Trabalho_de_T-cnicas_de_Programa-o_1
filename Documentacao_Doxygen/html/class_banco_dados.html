Detailed Description

Gerenciador central da conexão com o banco de dados SQLite.

  • Esta classe atua como o motor de persistência de baixo nível do sistema. Ela encapsula a complexidade da API nativa do SQLite (sqlite3), gerenciando o ciclo de vida do arquivo de banco de dados (abertura e fechamento) e garantindo a criação da estrutura física inicial (tabelas) necessária para o funcionamento das demais classes de Repositório.
